# NOIR — Luxury Barbershop Landing Page

React + Vite single-page site (Hebrew/RTL), styled with Tailwind CSS and animated with [framer-motion](https://motion.dev).

```bash
npm install
npm run dev      # local dev server
npm run build    # production build → dist/
npm run preview  # serve the built dist/
```

Deploy the contents of `dist/` to any static host. `vite.config.js` uses a relative `base`, so it also works from a subpath such as GitHub Pages.
