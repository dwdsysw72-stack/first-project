# TANUR: pizzeria landing page

American English landing page for a neighborhood pizzeria. React + Vite, animated with [framer-motion](https://motion.dev).

- **Style, colors, fonts:** picked with the `ui-ux-pro-max` skill (appetizing red `#DC2626`, Karantina + DM Sans, self-hosted).
- **Layout and motion:** guided by `taste-skill` (dials 7 / 7 / 4). Every animation has a job: hero entrance, the pizza turning as you scroll, a pinned sideways menu on desktop, count-up stats, and reveals. Reduced-motion users get a static page.

```bash
cd pizzeria
npm install
npm run dev      # local dev server
npm run build    # production build → pizzeria/dist/
```

Before going live, replace the placeholders listed at the top of `index.html` (phone, address, Instagram, sample reviews, Unsplash photos).
